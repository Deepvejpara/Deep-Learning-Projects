# 🎙️ Audio Deepfake Detection

A deep learning project that classifies audio recordings as **Real** or **Fake** using a Convolutional Neural Network (CNN).

The project converts raw audio into **Mel Spectrograms** and uses a CNN to learn patterns that distinguish genuine human speech from deepfake/synthetic speech.

## 📌 Project Overview

Audio deepfakes can be generated using techniques such as text-to-speech and voice conversion. This project explores a basic deep-learning approach for detecting such manipulated audio.

### Pipeline

```text
Audio File
    ↓
Load & Resample to 16 kHz
    ↓
Pad / Trim to 4 seconds
    ↓
Mel Spectrogram
    ↓
CNN
    ↓
Sigmoid Output
    ↓
Real / Fake
```

## 📂 Dataset

This project uses the **Voice Dataset for Audio Deep Fake** from Kaggle.

- Dataset: [Voice Dataset for Audio Deep Fake](https://www.kaggle.com/datasets/umairimran627/voice-dataset-for-audio-deep-fake)
- Dataset license: MIT
- Classes:
  - `fake` → label `0`
  - `real` → label `1`

The dataset already provides separate training, validation, and testing splits.

## 🧠 Preprocessing

Each audio file is:

1. Loaded using **Librosa**
2. Resampled to **16 kHz**
3. Limited to **4 seconds**
4. Padded with zeros when shorter than 4 seconds
5. Converted into a **128-bin Mel Spectrogram**
6. Converted from power scale to **decibels (dB)**
7. Given a channel dimension for CNN input

The resulting input shape is:

```text
128 × 126 × 1
```

## 🏗️ CNN Architecture

The model is a basic CNN designed for binary audio classification.

```text
Input
  ↓
Conv2D (32 filters)
  ↓
MaxPooling2D
  ↓
Conv2D (64 filters)
  ↓
MaxPooling2D
  ↓
Conv2D (128 filters)
  ↓
MaxPooling2D
  ↓
Flatten
  ↓
Dense (128)
  ↓
Dropout (0.5)
  ↓
Dense (1, sigmoid)
```

### Model Configuration

- Framework: **TensorFlow / Keras**
- Optimizer: **Adam**
- Loss: **Binary Crossentropy**
- Output activation: **Sigmoid**
- Batch size: **256**
- Epochs in the current experiment: **2**
- Total parameters: **3,304,193**

## 📊 Current Results

The current notebook was trained for **2 epochs** as an initial baseline.

| Metric | Result |
|---|---:|
| Training Accuracy (Epoch 2) | 90.65% |
| Validation Accuracy (Epoch 2) | 94.29% |
| Test Accuracy | **84.18%** |

> **Note:** These are the results from the current 2-epoch baseline experiment. Test performance can change with additional training, regularization, preprocessing changes, or other model architectures.

## ⚠️ Limitations

This is a **baseline deepfake audio classifier**, not a universal deepfake detector.

Performance can vary when the model encounters audio generated by synthesis methods or datasets that were not represented during training. Therefore, test accuracy on this dataset should not be interpreted as a guarantee of performance on arbitrary real-world audio.
